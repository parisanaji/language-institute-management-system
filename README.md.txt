# Language Institute Management System

Web-based management system for language institutes developed as a Bachelor's thesis in Software Engineering.

## Features
- Administrator panel for managing users, courses, and fees
- Instructor dashboard for grading and student management
- Student portal for course materials and communication
- Guest access for general information and registration

## Technologies
- PHP
- CodeIgniter (MVC architecture)
- MySQL
- HTML / CSS / JavaScript
- jQuery
- Bootstrap

## System Roles
- Administrator
- Instructor
- Student
- Guest

## Description
This system is designed to automate administrative and educational processes of language institutes through a web platform. It supports user management, messaging, course management, grading systems, and financial tracking.
